# 小嗨猜猜猜

聚会猜词游戏，iPhone 主屏幕 Web App（PWA）。手机横屏举起、屏幕朝向朋友，屏幕翻向地面算答对，翻向天空算跳过。

当前状态：设计阶段，尚未开始编码。
